# 🧱 Tiles Gallery

An interactive web application to explore, filter, and manage modern tile and surface collections.

---

## 📌 Project Overview

**Tiles Gallery** provides a digital showcase for interior designers, homeowners, and contractors to browse tile categories, view material specifications, manage custom listings, and save favorites in a responsive, modern web platform.

## 🛠️ Main Technologies

- **Frontend & Routing:** Next.js (React Framework)
- **Styling & UI:** Tailwind CSS, HeroUI, DaisyUI
- **Authentication:** BetterAuth
- **Database:** Mongodb
- **Deployment:** Vercel

---

## ✨ Key Features

- **Search & Filter:** Search tiles by name, material, category, finish, and price range.
- **User Authentication:** Secure email/password and Google login powered by  BetterAuth.
- **Responsive & Interactive UI:** Modern layout built with smooth animations and responsive components.
- **Material Specifications:** View detailed specifications and finishes for each tile product.
- **Favorites & Management:** Save favorite tile collections and manage custom tile listings.
