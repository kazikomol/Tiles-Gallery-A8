# 🧱 Tiles Gallery

An interactive web application to explore, filter, and manage modern tile and surface collections.


## 📌 Purpose

Tiles Gallery provides a digital showcase for interior designers, homeowners, and contractors to browse tile categories, view material specifications, manage custom listings, and save favorites in a responsive, modern web platform.

## ✨ Key Features

- **Search & Filter:** Search tiles by name, material, category, finish, and price range.
- **User Authentication:** Firebase-powered email/password and Google login.
- **Responsive UI:** Modern layout built with Tailwind CSS and DaisyUI.

## 🛠️ NPM Packages Used

- **Frontend & Routing:** `next.js`
- **Authentication & API:** `betterauth`
- **Styling & UI:** `tailwindcss`, `heroui`, `react-icons`  `react-icons`
- **Feedback & Animations:** `framer-motion`,`animate.css`
